Shared REPL sessions for coding agents

agent-repl lets you and your coding agents work in the same running Python, Julia, R or other supported session. Agents can use the variables and functions you define at the prompt, and you can inspect or change theirs as you work.

What happens in the demo

The imports and Lorenz function are loaded before filming. The Python example includes that setup.

  1. Pi integrates a Lorenz trajectory, stores it as a and plots the attractor.
  2. The operator sends b = odeint(lorenz, [1.0001, 1, 1], t) with !agent-repl-py, from Pi’s shell mode.
  3. Claude Code uses a and b to plot how their separation grows. Both plots appear inline on the REPL page.

Installation

You need Node.js 22 or later, tmux and the runtime you want to use. To install agent-repl and start Python:

npm install -g agent-repl
agent-repl python -d

Add the tools to Claude Code:

claude mcp add --scope user agent-repl -- agent-repl mcp

Ask Claude Code to use the shared Python REPL. To work at the same prompt yourself, run agent-repl attach python in another terminal. The Lorenz example also needs NumPy, SciPy and Matplotlib.

The setup guide covers Codex, OpenCode and other MCP clients.

Pi and the browser preview

agent-repl uses pi-repl’s session handling outside Pi. Inside Pi, use pi-repl to connect to the same sessions.

For a browser view of submitted code and saved plots, use agent-markdown-preview with --repl, as shown in the video.

Code runs with the REPL’s permissions. See the privacy and safety notes before connecting an agent.
