What happens in the demo

The imports and Lorenz function are loaded before filming. The example code includes that setup.

  1. Pi integrates a Lorenz trajectory, stores it as a and plots the attractor.
  2. The operator sends b = odeint(lorenz, [1.0001, 1, 1], t) with !agent-repl-py, from Pi’s shell mode.
  3. Claude Code reuses a and b to plot how their separation grows. Both plots appear inline on the REPL page.

Start a shared session

npm install -g agent-repl
agent-repl python -d

Add the tools to Claude Code:

claude mcp add --scope user agent-repl -- agent-repl mcp

Ask the agent to use the shared Python REPL. Join it from your own terminal with agent-repl attach python.

Requires Node.js 22+, tmux and your chosen runtime. The Lorenz example also uses NumPy, SciPy and Matplotlib.

Use your existing tools

Python, Julia, R and more. The setup guide covers Codex, OpenCode and other MCP clients.

Inside Pi, use pi-repl to join the same sessions. For the inline code and plots shown here, add agent-markdown-preview.

Agent code runs with your REPL’s permissions. Read the safety notes.
